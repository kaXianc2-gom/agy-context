# Context Lens (`/context`)

Use the `agy-context_agy_context_mcp` MCP tools:

- **`open_session_hud`**: Opens the in-conversation `Context` dual-column anatomy side pane (`{"conversationId": "<current-conversation-id>"}`).
- **`open_context_dashboard`**: Opens the global `Context Lens` cross-session dashboard (`{"range": "30d"}`).
- **`show_context_snapshot`**: Renders a single-row compact real-time HUD bar inline inside the conversation.
